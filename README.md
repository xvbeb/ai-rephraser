# AI Переписыватель | Neon Edition

Веб-приложение + десктопная версия для переписывания текста с помощью ИИ (Google Gemini API).
Поддерживает разные тона (нейтральный, формальный, bydlo, креативный и т.д.), чат для уточнений и тёмную/светлую тему.

## Возможности

- Переписывание текста в выбранном тоне
- Чат с ИИ для доработки и споров
- Десктопная версия на PyQt6 (локальный сервер или подключение к удалённому)
- Неоновый дизайн с поддержкой светлой и тёмной темы
- Копирование результата в буфер обмена

## Технологии

- Backend: Flask
- Frontend: HTML, CSS, JavaScript
- Десктоп: PyQt6 + QWebEngineView
- ИИ: Google Gemini API (gemini-2.5-flash по умолчанию)

## Установка и запуск

1. Клонируй репозиторий
```bash
git clone https://github.com/xbeb/ai-rephraser.git
cd ai-rephraser
```

2. Создай виртуальное окружение

python -m venv .venv
source .venv/bin/activate      # Linux/Mac
.venv\Scripts\activate         # Windows

3. Установи зависимости

pip install -r requirements.txt

4. Скопируй .env.example → .env и заполни ключи

cp .env.example .env
# открой .env и вставь GEMINI_API_KEY

5. Запуск

С GUI (ПО УМОЛЧАНИЮ)

* python main.py

Только сервер (без окна)

python main.py --no-gui

web/ — Flask приложение

## Изменения v2

Python 3.10+. Настройки находятся в `.env.example`. `SECRET_KEY` обязателен при
`APP_ENV=production`; локально при пустом значении создаётся случайный ключ на запуск.
Если выбранная модель недоступна вашему ключу, задайте доступную через `AI_MODEL`
(в ручной проверке использована `gemini-3.6-flash`).
Локальный сервер слушает `127.0.0.1:5000`; порт меняется через `PORT`.

`/rephrase` возвращает проверенный Pydantic JSON: `rewritten_text` и `changes`.
`POST /chat/stream` передаёт уточнения через SSE поверх fetch: события `delta`,
`done`, `error`. Частичный JSON от модели не разбирается. `POST /chat` остаётся
доступным без стриминга; `GET /chat` возвращает историю, `/chat/clear` очищает её.
Ошибки API имеют поля `error` и `code`; ошибка внутри потока приходит событием
`error`, поскольку HTTP-заголовки к этому моменту уже отправлены.

История привязана к подписанной cookie с ID, но хранится в памяти сервера:
до 256 сессий, TTL бездействия 1 час, до 20 сообщений / 60000 символов.
Вход ограничен 12000 символов, ответ — 24000. Старые пары сообщений удаляются
целиком. Новый `/rephrase` начинает новую беседу; неудачные генерации историю
не меняют. Одновременно для сессии выполняется один изменяющий запрос.
История исчезает после перезапуска. Текущее хранилище рассчитано на **один процесс**
с несколькими потоками; несколько workers требуют общего хранилища с блокировками.
Для публичного развёртывания нужны HTTPS, WSGI-сервер и отключённая буферизация SSE
в reverse proxy. RU/EN/UA остаются переключателем UI-предпочтения, не переводом интерфейса.

Проверки без запросов к Gemini:
```bash
pip install -r requirements-dev.txt
python -m pytest
```
